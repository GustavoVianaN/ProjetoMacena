# Macena Advogados · Central de atendimento

Protótipo React e Vite da assistente virtual e do painel interno do escritório.

```sh
npm install
npm run dev
```

Abra o endereço local exibido pelo Vite. Para gerar os arquivos de produção, use `npm run build`.

## Demonstrar o fluxo

1. Em **Atendimentos**, abra um caso para consultar o resumo, o histórico e os documentos registrados.
2. Em **Simular atendimento**, relate um problema fictício. A assistente identifica a área por palavras-chave, faz perguntas e registra um possível prazo.
3. Use **Encaminhar para a equipe**. No painel, escolha **Assumir atendimento** para registrar uma resposta local e concluir o caso.
4. Use **Clientes** e **Documentos** para localizar os registros.

A demonstração armazena registros no navegador e registra somente o nome dos anexos. Use exclusivamente dados fictícios. WhatsApp, IA generativa, transcrição de áudio, coleta de CPF e telefone, autenticação e integração processual ficam para a implementação de produção.
